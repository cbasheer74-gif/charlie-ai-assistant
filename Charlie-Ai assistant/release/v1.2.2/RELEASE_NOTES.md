# CHARLIE 1.2.2 (Build 106)

Local desktop update containing the current source changes:

- Preserve phoneme labels through live audio animation and close the mouth on silence.
- Add tongue articulation and eye/brow expression channels to the photo avatar rig.
- Use live response text for basic Hindi/Hinglish mood cues.
- Limit portrait rendering resolution to reduce CPU work in large windows.

Verification: 14 avatar and Lifetime entitlement tests passed before packaging.
These are 2D portrait improvements, not a Blender 3D face rig or verified exact
word-aligned lip synchronization. The reported mouth-opening quality still needs
visual and audio validation.

This release updates the local desktop executable. The downloadable installer
remains the previously published version.
