# CHARLIE v1.0.0 Stable Release Notes

**Version:** CHARLIE v1.0.0 (Build 102)  
**Release date:** 2026-09-21  
**Distribution:** `CHARLIE-Setup-1.0.0.exe` (150.6 MB)  
**SHA-256:** `6fb49d71f9aac37db833e2a6edf2972aaf07921e7df304dc11f23832fa7efa68`

## Highlights

- Faster, non-blocking startup and Settings opening, with smoother first spoken response.
- Reliable male/female neural-voice switching and gender-aware Hinglish responses.
- Pro AI Chat workspace with conversation memory, file context, and stronger answer routing.
- Companion profiles, routines, Daily IQ, Surprise Me, and ten voice games.
- Calendar/tasks, learning coach, meeting tools, family profiles, themes, subscription, profile, and About screens.
- Scroll-safe settings controls: mouse-wheel scrolling no longer changes focused selectors.
- Signed-update validation, health checks, and last-known-good rollback support.

## Compatibility

- Windows 10 and Windows 11, 64-bit.
- Filmora automation requires Filmora 14 or newer; FFmpeg workflows remain available without Filmora.
- Local Ollama answers require a compatible model installed and running; cloud/BYOK routing remains available.

## Distribution notes

- Existing user configuration, memory, and installed plugins are preserved during upgrade/uninstall by default.
- The unsigned installer may show Windows SmartScreen until production code signing is configured.
