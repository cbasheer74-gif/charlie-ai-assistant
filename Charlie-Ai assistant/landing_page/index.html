Trust & Verification

Security Grounded in System Truth

Verifiable security architecture designed for local safety, data protection, and user consent.

Windows DPAPI Protection

User credentials and API keys are encrypted at rest using the Windows Data Protection API (DPAPI). Never stored in plaintext.

Zero Bundled Secrets

Installer binaries and releases contain zero embedded secrets, private keys, or baked-in cloud vendor credentials.

Separated Data Boundaries

Binary program files install cleanly in Program Files; user state, configuration, and databases reside in user-scoped AppData.

Confirmation Gates

Destructive actions such as file deletion, system shutdown, or configuration changes require explicit user confirmation.

Single-Instance Protection

System mutex enforcement ensures only one authenticated Charlie runtime process operates at any time.

Transparent AI Processing

When cloud AI features are used, prompts are transmitted to configured providers (Google Gemini / Groq) over TLS. Local tools execute on-device.
