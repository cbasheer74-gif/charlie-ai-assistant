Quick Troubleshooting

Common installation questions:

  • Windows 10/11 SmartScreen prompt: Click "More info" → "Run anyway" if running an unsigned developer preview build.
  • Transferring to a new PC: Install CHARLIE on the new machine, log into your account, and click "Transfer License to This PC".
  • 10-Minute Daily Free Limit: The Starter plan timer runs only while CHARLIE is actively processing instructions. Background idle time does not deduct minutes.
