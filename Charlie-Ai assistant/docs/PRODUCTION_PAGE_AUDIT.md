# Production Page & UX State Audit

## Application Overview & Verified Context
- **Product Name:** CHARLIE AI Assistant (Windows Desktop Commercial Assistant)
- **Application Type:** Hybrid Local-First Desktop AI Application (PySide6 / Python) + Commercial Cloud Licensing & Account Server (FastAPI / SQLite WAL) + Customer Portal & Landing Page (HTML5 / Vanilla CSS / Modern JS) + Administrative Control Panel.
- **Payment & Licensing Model:** Razorpay payment gateway integration (Indian Rupees INR). Subscriptions: Basic (₹149/mo, 500 cr), Pro (₹299/mo, 1,500 cr), Pro+ (₹599/mo, 4,000 cr), Annual Pro (₹2,999/yr, 1,800 cr/mo, Save ₹589) + Non-expiring Credit Top-Up Packs. Single/Multi-PC hardware binding enforced via SHA-256 salted machine hashes.
- **Authentication:** JWT Bearer tokens (access + refresh) with Argon2/bcrypt password hashing. Self-service `/me` endpoints with mathematical IDOR immunity.
